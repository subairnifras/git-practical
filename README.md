# TO-DO LIST Project
# Project Overview
- The To-Do List Web Application is a simple and interactive task management project built using HTML, CSS, and JavaScript.
- It allows users to efficiently create, manage, and organize daily tasks through a clean and user-friendly interface.

This project focuses on strengthening core front-end development skills, including DOM manipulation, event handling, and basic UI design.
